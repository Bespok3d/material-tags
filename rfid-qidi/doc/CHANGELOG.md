# Changelog

## 0.1.0

- First release. Tap a QIDI spool on the reader and the lane knows what is on the reel: the material,
  its sub-type and the colour. That is everything a QIDI tag carries, so the weight, the diameter and
  the temperatures keep coming from your slicer profile or from Spoolman, as they always did.
- Uses the reader you already have. Nothing to plug in, nothing to buy, nothing to set up.
- It only reads. It never writes anything onto a tag, so a QIDI spool stays exactly as QIDI made it.
- A spool that is not QIDI's own but carries the same kind of tag reads as QIDI-compatible.
- A spool whose material the card names in a way this plugin has not met before still tracks, and the
  log says exactly what the card said, so it can be named in the next release.
